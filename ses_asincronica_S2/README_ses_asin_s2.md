Repositorio para el curso de analisis de señales mixtas. Primer semestre 2026.

Tarea 1 - Semana 2 Asincrónica - Números Complejos

Para utilizar el simulador del circuito necesita Python 3.xx. Además, debe instalar algunas librerías (utilizando el comando pip3 install <package_name>):

matplotlib.pyplot
numpy
sympy

Una vez hecho eso puede utilizar el siguiente comando en la terminal del proyecto:

python3 simulador_circuito.py
